## Peer-review process

1. Create a GitHub issue using `peer-review-issue.md` as the body.
2. Ask a classmate to open the cited original source and trace one observation to the proposed feature and check.
3. Record the reviewer's actual feedback and link it here.
4. Decide whether to implement, investigate, defer, or decline the suggestion. Explain the reason in the issue.
5. Make the documentation or code change and include the issue number in the commit message where possible.
6. Link the commit or pull request in the issue and explain exactly how the change was checked.
7. Ask the reviewer to retry the check. Only close an issue after the reviewer confirms a resolved item. Keep unfinished items open with a next step.
